1．课题来源、目的和意义
随着 Web 技术的不断发展，企业和组织内部往往同时运行多个 Web 应用系统。在实际运行过程中，这些系统普遍存在用户身份管理分散、认证方式各自实现、权限控制策略不统一等问题，不仅增加了系统开发和运维成本，也使整体安全防护体系难以形成统一有效的控制，一旦某一系统认证或授权机制设计不当，极易引发越权访问等安全风险。
身份认证与访问控制是 Web 应用安全体系中的基础性安全机制。在多 Web 应用并存的环境下，将身份认证与授权能力从具体业务系统中剥离出来，构建统一的身份认证与访问控制服务，是提升系统安全性、规范性和可管理性的有效途径。
本课题来源于多 Web 应用环境下对统一身份安全管理的实际需求，要求学生设计并实现一个面向 Web 应用的统一身份认证与访问控制服务。该系统以集中式身份认证、访问控制和安全审计为核心，通过标准化接口为多个 Web 应用系统提供统一的安全服务能力，从而降低业务系统重复开发认证与授权功能的成本，提升 Web 应用整体安全防护水平，具有较强的工程实践意义和应用价值。
2．课题任务的主要内容和要求（包括原始数据、资料、技术参数、工作要求等）
本毕业设计采用 B/S 架构，围绕统一身份认证与访问控制服务的设计与实现展开。课题要求学生从系统级安全服务的角度出发，将身份认证、会话管理、访问控制和安全审计等功能进行集中设计与实现，构建一个可独立部署、可被多个 Web 应用系统接入的统一安全服务平台
需要完成以下基本功能：
（1）统一身份认证服务模块：设计并实现统一的用户身份认证服务模块，集中处理来自不同 Web 应用系统的用户认证请求。该模块基于用户名和密码的认证方式，采用加盐哈希等安全技术完成用户密码的安全存储与校验，并通过标准化接口对外提供身份认证服务，使认证逻辑不再依赖具体业务系统。
（2）身份凭证与会话管理模块：设计并实现身份凭证与会话管理模块，负责用户认证成功后的身份凭证生成、校验、过期与失效控制。通过统一的会话管理机制，实现用户登录状态的集中维护，支持身份认证结果在多 Web 应用场景下的安全复用，防止会话滥用和非法访问。
（3）基于角色的访问控制模块（RBAC）：设计并实现基于角色的访问控制模块，构建用户、角色、权限与受控资源之间的映射关系。通过集中配置角色与权限，实现对 Web 应用接口和功能的细粒度访问控制，确保用户仅能访问其授权范围内的系统资源，防止未授权访问和越权操作。
（4）统一授权校验接口模块：设计并实现统一的授权校验接口模块，为接入系统提供标准化的身份校验和权限判断服务。业务系统在处理用户请求时，通过调用该模块完成授权决策，从而将权限校验逻辑从业务系统中剥离，体现认证与授权能力的服务化和独立性。
（5）多 Web 应用系统接入管理模块：设计并实现多 Web 应用系统接入管理模块，对接入统一认证服务的业务系统进行集中管理。通过为不同业务系统分配系统标识和接入凭证，实现系统级身份校验，确保只有合法注册的系统才能调用认证与授权接口，体现统一安全服务的可扩展性和独立部署能力。
（6）账户安全控制与风险防护模块：设计并实现账户安全控制与风险防护模块，针对身份认证阶段的常见安全威胁，完成登录失败次数限制、账户临时锁定等安全防护功能，对异常登录行为进行限制和处置，降低暴力破解和非法登录攻击风险。
（7）安全管理与审计模块：设计并实现安全管理与审计模块，对用户身份认证行为、授权决策结果以及异常访问事件进行统一记录和管理。该模块为系统管理员提供安全日志查询、用户状态管理、角色与权限配置以及安全策略维护等功能，实现系统安全策略的集中管理与关键安全行为的可审计性。
（8）系统测试与运行验证模块：对统一身份认证与访问控制服务的各功能模块进行功能测试和安全性测试，重点验证系统在多 Web 应用接入和多用户并发访问场景下的稳定性、正确性和可用性。
